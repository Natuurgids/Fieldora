# Build 33.5 Analytics Reporting Expansion

- Replaced the placeholder Statistics area with an interactive Analytics workspace.
- Added overview metrics for media entries, observations, identified observations, and confirmed observations.
- Added dependency-free, theme-aware pie and horizontal bar charts.
- Added breakdowns by media type, identified media type, species/taxonomic group, country, region/locality, capture month, and review state.
