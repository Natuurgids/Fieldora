# Build 33.5 Phase 6 — Models Page Redesign

The Models workspace now presents the complete operational contract for every model:

- Purpose
- Produces
- Dependencies
- Works With
- Typical Workflow
- Offline Ready
- Runtime Health

The catalog now carries explicit `produces` documentation for every bundled model. Runtime health remains live and is derived from installation state, dependency checks, and the model manager's validated runtime detail. Existing installation, activation, deactivation, licensing, parameter controls, capability routing, offline execution, review flow, and provenance behavior are unchanged.

This release includes the previously approved Phase 7 Knowledge Sources separation.
