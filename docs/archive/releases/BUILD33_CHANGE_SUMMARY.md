# Build 33.0 Change Summary

Build 33.0 delivers the approved Knowledge Base / AI Review presentation milestone while preserving the proven BioCLIP services and review actions.

## Photo AI Review

The Photos workspace is rebuilt as a four-part review surface:

1. persistent filters;
2. suggestion queue;
3. source and model-input visual evidence;
4. decision, provenance and explanation panel.

The exact persisted BioCLIP input snapshot is displayed in a dedicated card rather than embedded inside a long text document. The source photograph and model input remain separate evidence objects.

Review actions, keyboard shortcuts, generation, cancellation, observation history, regional evidence and acceptance semantics remain on the existing application services.

## Multimodal Knowledge Base

The Build 32 multimodal tabs remain available for Overview, Photos, Sounds, Videos, Documents, Comparisons and Accepted Knowledge. Specialized media reviewers remain independent rather than being forced into the photo layout.
