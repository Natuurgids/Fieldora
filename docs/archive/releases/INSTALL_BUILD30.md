# Install Aperture Build 30

Build 30 is a clean-install field-test release. Do not point it at a development library from an earlier build.

## Windows
Extract the Windows archive and run `Install Aperture.cmd`.

## Linux
Extract the Linux archive and run `bash "Install Aperture Linux.sh"` or `bash scripts/install_linux.sh`.

After installation, create a new Aperture Library and retain the generated diagnostic and Activity Centre records with any field report.
