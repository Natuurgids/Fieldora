# Install Aperture Build 31

Build 31 is a clean-install field-test release.

## Windows

Extract the Windows archive and run `Install Aperture.cmd`.

## Linux

Extract the Linux archive and run:

```bash
bash "Install Aperture Linux.sh"
```

To remove Linux application components while preserving all Aperture Libraries and media:

```bash
bash "Uninstall Aperture Linux.sh"
```
