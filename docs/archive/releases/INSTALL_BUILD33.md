# Install Aperture Build 33.1

Build 33.1 is a clean-start field-test release.

Windows: extract the Windows archive and run `Install Aperture.cmd`.

Linux: extract the Linux archive and run `bash "Install Aperture Linux.sh"`.

Create a new Aperture Library. Development-library migration is not included.
