# AI Platform

AI Platform is the administration workspace for governed AI providers, models, and MCP servers. It is separate from day-to-day identification and review in Knowledge & AI.

## Configure AI components

Review registered providers, models, and MCP servers before adding or changing a component. Record the endpoint or provider relationship, network classification, and enabled state deliberately. A model or provider being registered does not automatically make it appropriate for every project or purpose.

## Security and access

AI Platform is capability-gated administration content. Keep credentials and secrets out of descriptive fields, and use approved secret-management mechanisms for sensitive connection material. Network and policy restrictions still apply when a component is enabled.
