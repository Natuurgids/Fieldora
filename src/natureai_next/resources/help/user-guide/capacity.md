# Capacity

Capacity combines work schedules, absences, obligations, and project allocations so teams can understand available effort before committing work.

## Review capacity

Use the summary and lists to compare scheduled availability with unavailable periods and allocated hours. Records can be associated with a project and user, with dates and hours per week where applicable.

## Add capacity records

Choose the appropriate record type, enter the responsible user and timing, and save the record. Treat capacity as planning information rather than an authorization grant: access to projects and other workspaces continues to be enforced separately by policy.
