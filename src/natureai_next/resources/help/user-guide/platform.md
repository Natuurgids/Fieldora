# Platform

Platform provides an administration view of Fieldora feature parity and implementation status across supported clients. Use it to understand which registered features are implemented, partial, or missing on each platform.

## Review platform status

Refresh the workspace to load the current parity summary and feature registry. Compare Windows desktop, Linux desktop, and server implementation states before planning a workflow that depends on a specific client.

## Interpretation

Platform status is operational metadata, not an authorization override. A feature can be implemented while remaining unavailable to your identity because workspace and action capabilities are evaluated separately.
