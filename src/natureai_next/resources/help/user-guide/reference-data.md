# Reference Data

Reference Data manages controlled values used consistently across Fieldora. Examples include classifications, codes, categories, and other reusable values that should not be retyped differently in each record.

## Maintain values

Choose the reference domain, code, display name, description, and active state. Prefer stable codes and clear display names. Deactivate obsolete values when they should no longer be selected instead of silently reusing a code for a different meaning.

## Governance

Reference Data is an administration capability. Changes can affect validation and user choices elsewhere, so review downstream use before renaming, deactivating, or replacing established values.
