Aperture Offline Map Builder

Aperture uses Planetiler 0.10.2 (Apache-2.0) and Eclipse Temurin Java 21
(GPL-2.0 with Classpath Exception). When binaries are not bundled, Aperture
retrieves the official releases once and caches them under offline-maps/.map-tools.
After the regional OSM source and toolchain are cached, map generation and map
use are fully offline.
